AniList Mentions

Connect with an AniList API token. Your AniList password is never entered or stored here.

How to get a token
  1. Create an app in AniList Developer settings.
  2. Set its Redirect URL to https://anilist.co/api/v2/oauth/pin.
  3. Enter your app's Client ID below, then click Authorize.
  4. Copy the access token shown by AniList and paste it above.

Token is stored locally in Chrome extension storage and used only for AniList GraphQL requests.
